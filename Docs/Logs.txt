NARAD - QC : Network Architecture for Routing, Authentication and Delivery in Quantum Communications

HOW CAN A QUANTUM SECURE COMMUNICATION NETWORK DYNAMICALLY SELECT RELIABLE, AUTHENTICATED, LOW-QBER PATHS BETWEEN MULTIPLE USERS?

Phase Plan : 
    Phase 0 : 
        Goal : Rebuild point to point CrypTon key generation and AES baseline.
        
        Objective : Prove the original point-to-point system is working as the baseline.

    Phase 2 : 
        Goal : Add a single repeater so that Alice <--> Bob chain becomes ===> Alice <--> R1 <--> Bob

        Objective : Measure whether splitting distance improves stability and key availability.

        Metrics :
            * end-to-end QBER
            * key generation time
            * accepted key rate
            * maximum supported distance
            * improvement over direct link
        
        Question : Can a single repeater improve the effective QKD range and reliability compared to direct transmission?

    Phase 3 : 
        Goal : Introduce multi repeater chain instead of a single repeater

        Objective : Study hop count, synchronization delay, bottleneck links, and end-to-end key generation.

        Variables:
            * Number of repeaters: 1, 2, 3, 5
            * Equal-distance segments vs unequal-distance segments
            * Fixed total distance vs increasing total distance

        Metrics:
            * total end-to-end key latency
            * weakest-link bottleneck
            * cumulative trust score
            * average QBER
            * accepted key probability
            * synchronization delay

        Question : How does repeater-chain length influence stability, latency, and key availability?

    Phase 4 : 
        Goal : Introduce multiple possible repeater paths and Dilithium-based authentication over the classical control channel.

        Objective : Choose paths using quantum-aware metrics, not just shortest distance.

        Possible path score = weighted combination of:
            - total distance
            - expected QBER
            - key generation latency
            - hop count
            - link success probability
            - repeater trust/authentication status

    Phase 5 : 
        Goal : Multi-User Quantum Network Topology

        Build a small network with:
            * 4 users
            * 10 repeaters
            * multiple weighted links
            * authenticated routing
            * best-path selection
            * session key generation
            * AES encrypted message delivery

        Objective : NARAD-QC becomes a small quantum-secure communication network simulator.

        QUESTION : How can a quantum-secure communication network dynamically select reliable, authenticated, low-QBER paths between multiple users?

    Instead of accurately replicating the physical quantum repeater, we model the essentials of it in the simulation. A long quantum channel is decomposed into shorter elementary quantum links. Each link attempts entanglement generation. If both elementary links succeed, the repeater performs entanglement swapping and creates an effective end-to-end quantum connection between Alice and Bob.

    Phase 2 models entanglement generation probabilistically, where each elementary Bell-pair generation attempt succeeds according to the photon survival probability of the corresponding quantum link. Successful attempts produce Bell-pair objects stored in repeater memory, and end-to-end entanglement is created through an abstract entanglement-swapping operation.

    Attempt to generate a Bell pair across one elementary quantum link.
    Phase 2A abstraction:
    - Success probability is approximated using link photon survival probability.
    - Successful attempt returns a BellPair object.
    - Failed attempt returns None.

    The repeater does not learn the key/message.
    It only helps convert two elementary entangled links
    into one end-to-end entangled link.

    Memory-assisted single quantum repeater model.

    Topology:
        source ---- repeater ---- destination

    Process:
    1. Try generating BellPair(source ↔ repeater).
    2. Try generating BellPair(repeater ↔ destination).
    3. Store successful Bell pairs in quantum memory.
    4. Retry only failed side.
    5. Once both Bell pairs exist, perform entanglement swapping.
    6. Output BellPair(source ↔ destination).

    Phase 2A first evaluates the ideal repeater-assisted upper bound, assuming perfect Bell-state measurement and no fidelity degradation. This isolates the effect of memory-assisted segmentation. Later experiments relax this assumption by varying swapping success probability and Bell-pair fidelity. 

    Each elementary Bell-pair generation attempt is modeled as a Bernoulli trial whose success probability is determined by the fiber survival probability of the corresponding quantum link.

    Phase 2A assumes ideal Bell-pair fidelity and perfect memory, isolating the effect of distance and storage-assisted entanglement generation.
